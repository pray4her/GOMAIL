sequenceDiagram
    participant Client
    participant API_Server as API Server (Gin)
    participant Redis
    participant Task_Dispatcher as Task Dispatcher
    participant Email_Workers as Email Workers (Pool)
    participant Aliyun_DM as Aliyun Mail

    Client->>API_Server: POST /api/v1/tasks
    API_Server->>API_Server: 认证 & 验证
    API_Server->>Redis: ZADD tasks:scheduled (task_id)
    API_Server-->>Client: 201 Created (task_id)

    loop 定时轮询 (e.g., every 10s)
        Task_Dispatcher->>Redis: ZRANGEBYSCORE (查询到期任务)
        Redis-->>Task_Dispatcher: [due_task_id_1, ...]
        Task_Dispatcher->>Redis: ZREM (移除)
        Task_Dispatcher->>Redis: LPUSH tasks:created (due_task_id_1)
    end

    Task_Dispatcher->>Redis: BRPOP tasks:created (等待新任务)
    Redis-->>Task_Dispatcher: task_id_1
    Task_Dispatcher->>Task_Dispatcher: 获取任务详情, 渲染模板...
    Task_Dispatcher->>Redis: LPUSH email:sending (email_job_1)
    Task_Dispatcher->>Redis: LPUSH email:sending (email_job_2)

    Email_Workers->>Redis: BRPOP email:sending (并发消费)
    Redis-->>Email_Workers: email_job_1
    Email_Workers->>Aliyun_DM: 发送邮件
